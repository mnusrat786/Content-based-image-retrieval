

# Content-Based Image Retrieval (CBIR)

**Content-Based Image Retrieval (CBIR)** is a technique used to search and retrieve images from large-scale datasets based on their actual visual features such as color, texture, and shape—rather than relying on manually tagged metadata or keywords.

---

## 📂 Dataset

This project uses the **COREL Image Dataset**, which contains approximately **10,800 images** divided into **80 categories**. Each category represents a different visual theme, including:

- **Natural scenes**: `autumn`, `cloud`, `iceberg`, `waterfall`
- **Animals & objects**: `dog`, `elephant`, `tiger`, `bonsai`
- **Man-made items**: `castle`, `train`, `ship`, `steam-engine`
- **Others**: `aviation`, `primates`, `stalactite`

**Dataset link**: [COREL Dataset Information](https://sites.google.com/site/dctresearch/Home/content-based-image-retrieval)
